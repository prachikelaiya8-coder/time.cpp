# Time Converter in C++

This is a simple C++ program that converts total seconds into hours, minutes, and seconds.

## About the Project

I created this project to practice basic C++ programming and understand how to use classes, objects, and functions.

The program takes total seconds as input from the user and converts them into HH:MM:SS format.

## Example

**Input:**

```text
Enter total seconds: 3665
```

**Output:**

```text
HH:MM:SS => 1:01:05
```

## Concepts Used

* C++ Programming
* Classes and Objects
* Member Functions
* User Input and Output
* Arithmetic Operators
* If Statement

## How to Run

1. Download or clone this repository.
2. Open the C++ file in your code editor.
3. Compile and run the program.
4. Enter the total seconds.
5. The program will display the converted time in HH:MM:SS format.
